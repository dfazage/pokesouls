# Musiques perso (usage privé, non publiées)

Déposez ici des fichiers OGG nommés comme l'ID de piste en minuscules (identiques à `assets/audio/music/`), par exemple `boss_mewtwo_p1.ogg`.
Pour chaque ID : si le fichier existe ici (et que la couche perso est active), il est joué ; sinon la piste libre de `assets/audio/music/` ; sinon rien.

La couche perso est active en local (localhost) et coupée sur le site publié. Forcer : `?perso=1` ou `?perso=0` dans l'URL.
Ce dossier est ignoré par git (seul ce README est suivi). Les reprises sont des œuvres dérivées : ne pas les publier sans accord des ayants droit.

IDs : MENU_STARTER, MAP_1 à MAP_6, MINIBOSS_A, MINIBOSS_B, SUBBOSS_BIRDS, SUBBOSS_KINGS, SUBBOSS_KINGS_ALT, BOSS_MEWTWO_P1, BOSS_MEWTWO_P2, BOSS_MEW, JINGLE_DEATH, JINGLE_VICTORY.
Pour les 17 pistes en boucle, assurez des boucles propres ; les JINGLE_* se jouent une seule fois.
